# Travel & Tourism Interactive Dashboard

เว็บไซต์ Dashboard สำหรับวิเคราะห์ข้อมูลการเดินทางและการท่องเที่ยว โดยนำเสนอข้อมูลในรูปแบบกราฟและตัวเลขสรุป เพื่อให้สามารถดูข้อมูลและเปรียบเทียบได้ง่ายขึ้น

## ฟังก์ชันหลัก

* แสดงจำนวนการจองตามประเทศปลายทาง
* แสดงจำนวนการจองในแต่ละเดือน
* แสดงสัดส่วนประเภทการเดินทาง
* แสดงความสัมพันธ์ระหว่างจำนวนคืนพักกับค่าใช้จ่าย
* กรองข้อมูลตามประเทศ
* กรองข้อมูลด้วยการคลิกประเภทการเดินทาง
* แสดง Tooltip และ Animation บนกราฟ

## เทคโนโลยีที่ใช้

* HTML
* CSS
* JavaScript
* Chart.js
* SheetJS (อ่านข้อมูล Excel)

## วิธีใช้งาน

1. เปิดโปรเจกต์ผ่าน Web Server เช่น Laragon
2. ตรวจสอบว่าไฟล์ข้อมูลอยู่ที่ `data/Travel And Tourism.xlsx`
3. เปิดไฟล์ Dashboard ผ่าน Web Server
4. เลือกประเทศหรือประเภทการเดินทางเพื่อกรองข้อมูล
